# 🌱 Projeto Agrinho 2026 - Tecnologia, Agricultura e Sustentabilidade

Este projeto foi desenvolvido especialmente para a **Categoria Programação/Robótica do Concurso Agrinho 2026**. Trata-se de uma plataforma web interativa e imersiva que conecta a inovação tecnológica no campo à preservação dos ecossistemas locais, demonstrando como a agricultura digital pode caminhar lado a lado com a sustentabilidade.

🚀 **[Clique aqui para acessar o projeto publicado](https://laiany-bento.github.io/PROJETO-AGRINHO-2026/)**

---

## ✨ Funcionalidades Principais

* 🌅 **Clima Dinâmico:** O site detecta o horário real do computador do usuário (Manhã, Tarde ou Noite) através de JavaScript e altera automaticamente o gradiente de fundo e o contraste, simulando os ciclos do dia no campo.
* 📋 **Central de Indicadores Agro:** Um hub interativo onde o usuário seleciona estados do Brasil ou macrorregiões do Paraná para carregar dados de produção agrícola, informações ambientais e curiosidades tech em tempo real.
* 🔬 **Laboratório Tech Interativo:**
    * *Simulador de Solo:* Uma barra interativa que simula os níveis de umidade da terra e ativa um sistema visual de irrigação automatizada.
    * *Calculadora Ecológica:* Avalia a economia de água gerada por tecnologias de precisão com base no tamanho da lavoura.
    * *Decisão no Campo (Mini-RPG):* Simulador de gestão onde o usuário toma decisões estratégicas e vê o impacto instantâneo na Produção, Natureza e Caixa da fazenda.
* 🏆 **Quiz Sustentável:** Desafio de perguntas e respostas sobre o agro moderno que gera feedbacks instantâneos e concede medalhas exclusivas de acordo com a pontuação do aluno.

---

## ♿ Acessibilidade e Inclusão

O projeto foi construído seguindo diretrizes de boas práticas de acessibilidade na web, contando com uma barra de ferramentas exclusiva:
* **Modo Escuro / Alto Contraste:** Otimização para leitura confortável e suporte para pessoas com baixa visão.
* **Fonte para Dislexia:** Opção de alteração tipográfica (`OpenDyslexic` / estilo adaptado) para facilitar a leitura.
* **Navegação Sem Mouse:** Interface totalmente navegável via teclado (teclas `Tab`, `Enter` e `Espaço`).

---

## 🛠️ Tecnologias Utilizadas

O projeto foi desenvolvido de forma pura, focando em performance, sem a necessidade de frameworks pesados:

* **HTML5:** Estruturação semântica do conteúdo e elementos de acessibilidade (Tags `aria`).
* **CSS3:** Design responsivo, animações de rolagem (*scroll animation*) e transições suaves de cores para o clima dinâmico.
* **JavaScript (Vanilla):** Lógica dos simuladores, manipulação dinâmica do DOM, controle de tempo real e banco de dados local para os indicadores.
